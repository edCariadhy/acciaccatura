# Acciaccatura Wiki

In-repo knowledge base. Lives under version control and changes through the same
pull request + review + CI as the code it describes — there is **no** GitHub wiki
(that would bypass review and drift by construction).

Conformance floor for every page here: see
[standards/frontmatter-schema.md](standards/frontmatter-schema.md). The gate is
`npm run docs:check`.

## Sections

- [standards/](standards/index.md) — engineering principles and contracts that govern the code.
- [log.md](log.md) — running record of what's built, verified, and open, most recent first.
